# 🏥 Le RDV Medical 

Application web de gestion de rendez-vous médicaux permettant aux patients de prendre des rendez-vous avec des médecins, et aux médecins de gérer leurs consultations.

---

## 📌 Description

Cette plateforme permet :

- 👨‍⚕️ Inscription et gestion des médecins
- 🧑‍💻 Inscription et gestion des patients
- 📅 Création et gestion des rendez-vous médicaux
- 🔍 Recherche de médecins
- 📊 Suivi des rendez-vous

---

## ⚙️ Technologies utilisées

### Frontend
- Angular
- TypeScript
- HTML / CSS
- Bootstrap / Angular Material

### Backend
- Node.js
- Express.js

### Base de données
- MongoDB
- Mongoose

---

## 🧩 Fonctionnalités

### 👤 Authentification
- Inscription / Connexion
- Rôles : Patient / Médecin
- Authentification sécurisée (JWT)

---

### 🧑‍⚕️ Médecins
- Créer et modifier un profil
- Ajouter disponibilités
- Gérer les rendez-vous
- Accepter / refuser les rendez-vous

---

### 🧑 Patients
- Créer un compte
- Rechercher un médecin
- Réserver un rendez-vous
- Consulter ses rendez-vous

---

### 📅 Rendez-vous
- Création de rendez-vous
- Choix date et heure
- Liaison patient ↔ médecin
- Gestion des statuts
